# Controls (Advanced Warfare mapping on SA)

Default PC. Rebind look in GInput. Pack toggle is **F4** so it does not steal **F6** from the companion switcher.

| Action | Key | Notes |
|---|---|---|
| Look | Mouse | From FP camera plugin |
| Move | WASD | Vanilla |
| Jump / Exo boost | Space | First tap = jump. Second tap in air = boost (2 charges) |
| Exo dash | Double-tap W / A / D / S | Short burst, 1.4s cooldown. S is backdash. |
| Slide | C while holding W | Ground only |
| ADS | RMB | Tight crosshair |
| Fire | LMB | Vanilla + hitmarker script |
| Toggle pack | **F4** | Exo + HUD + combat + loadout |
| Status cheat | type AWFPS | Prints charges |
| Assault class | 8 | M4 + Deagle. Same key again does nothing. |
| Heavy class | 9 | Shotgun + RPG |
| Specialist class | 0 | Sniper + MP5 |

## Stack with GroveLink / switcher

| Key | Owner |
|---|---|
| K | GroveLink phone |
| H / F6 | Companion switcher |
| F4 | This pack |

## Exo economy

- Boost charges: **2**
- Recharge: **2.8 seconds** each while grounded
- Dash cooldown: **1.4 seconds** shared across W/A/S/D
