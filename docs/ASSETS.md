# Assets — what you may use

## Shipped in this pack (original)

SVG sights in `assets/crosshairs/`. Raster PNGs from `tools/generate_crosshairs.py`.

## Packing a TXD so CLEO can DRAW_SPRITE

1. Install TXD Workshop or Magic.TXD.
2. Import PNGs as `aw_default` `aw_ads` `aw_shotgun` `aw_sniper` `aw_hit` `aw_hiths`.
3. Save as `modloader/SA_AW_FPS/aw_hud.txd`.

Until then, `AW_FPS_HUD.txt` draws boxes.

## Do not use

- Anything extracted from an Advanced Warfare `.pak` or `.ff`
- Official Atlas / KVA logos
- Rockstar `anim.img` dumps
