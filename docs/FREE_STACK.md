# Recommended free stack (community, not bundled)

Install each from the author’s page. Versions change; search the name.

## Must-have

- SilentPatch SA — CookiePLMonster
- ASI Loader — same
- CLEO 4.4.3 or CLEO 5 — cleolibrary
- CLEO+ — Junior_Djjr / MixMods
- ModLoader — Link2012
- GInputSA — CookiePLMonster
- Sanny Builder 3/4 — Seemann

## First-person camera (choose one)

- First Person 3.0 (BoPoh) + MixMods “fixed” + FixPack for FP 3.0
- Ultimate First Person (plugin-sdk, Nexus `gtasanandreas/mods/3048`)
- Zolika ZMenu custom first-person camera

## Combat flavour that already exists

- Call of Duty Combat Mod 0.5a (ThePedro004) — hitmarkers, XP popups, killstreaks
- GTA SA War / Army Mod — sandbox soldier loop, airstrike menu

You can run Combat Mod 0.5a **instead of** `AW_FPS_Combat.txt` if you want a battle-tested hitmarker. Do not run both; they will double-draw.

## Weapons / skins (author pages only)

- Search GTAinside: “Advanced Warfare Ohm”, “ATLAS Soldiers”
- MixMods weapon packs marked “replace Colt/AK/M4”

## Multiplayer (different project)

- SA-MP / open.mp gamemode “COD Warground” style (see GitHub `sjns19/samp-cod-wg` as historical reference)
- That is a server, not a single-player ASI. Do not mix it into this folder.
